# 纯 RL 规模与机制扩展：冻结理论和实验方案

本方案在任何新增正式训练前冻结。范围是 degree30、四类固定窗口合成分布、自身拓扑线长奖励；不调用 GeoSteiner、MST、FLUTE、最优标签或外部预训练权重。坐标合法性检查、自己输出树的线长计算与贪心网络 rollout 是环境和策略评价，不是构造参考解的求解器。本轮不声称训练了 Wasserstein 对抗生成器。

## 1. 已知证据与可检验猜想

上一轮独立验收通过。ME 的三个种子最佳点均在12288步；末2048步验证均值下降约0.49%、最坏组下降约0.50%。MG同预算比ME差，9个GroupDRO运行权重几乎全集中到edge_bias。因此同时检验计算预算不足、优化步长不合适、梯度尺度/训练推理差异、原始长度组难度混淆、batch方差、模型容量不足。后四项是猜想，不把权重集中直接当作因果证明。

记策略为πθ(A|X)，自身拓扑环境成本为L(X,A)，四组风险为Rg=E[L|g]。ERM目标为四组平均风险。自批评梯度用停止梯度的网络贪心成本bθ(X)：(L-b)∇logπ。baseline只依赖X、当前网络和已有状态，不依赖本次采样动作；不用参考最优解。

## 2. 单因素筛选矩阵

从已验收ME12288的完全相同Actor、Adam、BatchNorm和RNG状态分别出发，种子101/102/103，跑到20480。每组均匀采样、原batch64、原模型128维/3层为默认。

|代号|唯一主要改动|待检验问题|
|---|---|---|
|E50|保持lr=5e-5|增加训练预算是否继续有收益|
|E20 / E100|lr=2e-5 / 1e-4|末段步长偏大或偏小|
|COS|从12288至49152余弦5e-5降至5e-6|平滑退火；筛选与晋级使用同一全局曲线|
|WD|AdamW、decoupled decay=1e-4，继承Adam动量|轻度正则化，视为优化器方案而非纯步数效应|
|BNF|采样时冻结BN统计，其他训练机制不变|训练/推理归一化差异|
|ADV|优势除以上一批次EMA标准差，beta=.99，最小尺度.05|梯度尺度；不能用当前动作批次估计的尺度伪称无偏|
|D4|每个net随机坐标轴交换/反射|几何对称增强；原始分布上评价，grid组训练分布会改变|
|GD|原始风险乘法权重，eta=.01|原方法在相同父模型的对照|
|GDF|GD权重与均匀权重混合，uniform_mix=.2|使每组权重至少.05、至多.85|
|GDS|GD eta=.001|权重移动速度|
|GDN|风险和梯度同时除以固定父模型组成本ag|归一化组难度，目标改变必须明确|
|GDNF|GDN加uniform_mix=.2|预注册二因素组合|
|B256|batch256，学习率保持5e-5|更多样本或更大batch；两个预算对照分开报告|

GroupDRO在步t用旧qt加权Actor梯度，然后由当前采样风险更新下一步权重，不能反过来。内部乘法权重r'=softmax(log r+eta*R)，实际q=(1-alpha)r+alpha/4；归一化分支使用R/ag且Actor梯度也除以ag。ag仅来自独立训练校准坐标上父模型贪心线长，不来自验证或测试，更不是最优参考。所有分支从均匀组权重开始，清楚标记与旧MG续跑的差别。

B256由连续四个batch64基础数据块组成。其12288→14336与E50的12288→20480看过完全相同的新训练net；其12288→20480与E50同新增更新数，但样本数为4倍。采样动作和BN行为不可能完全配对。不得只报更新数就宣称batch优越。

容量实验另用201/202/203，从随机初始化训练BASE(128维3层)、WIDE(256维3层/FFN1024)、DEEP(128维6层)，均训练20480步，batch64，前8192步lr1e-4、之后5e-5；解码器宽度保持原值。数据相同、步数相同，初始权重由于架构不同不相等，参数量/FLOP/时间不匹配，必须报告计算成本。

## 3. 预注册晋级和长训练

第一阶段51个筛选训练任务：14个延长方案×3种子，加3种架构×3种子。另将104/105两个与筛选无关的父模型预训练提前放入第一阶段队列，因此首批队列共53项；优先较长的容量任务以减少GPU闲置尾部。所有候选完整跑完同预算筛选，不因测试排名提前停止。E50必进第二阶段并到49152步。

其余延长方案按固定20480端点选择：均值最好的合格方案和最坏组最好的合格方案，各最多一个，去重后最多2个。合格条件：主指标平均改善≥0.2%、至少2/3种子改善，另一指标恶化≤1%；B256仅作预算消融不晋级。不同目标允许选中同一方案，但不补选第二名。只有验证集参与决策。

晋级方案与E50在旧3种子上从筛选最新完整状态继续到49152。新种子104/105先从随机初始化训练同协议ME父模型到12288，然后训练这些已选方案到49152。额外种子不重新选方案。最终报告5种子整体，同时单列2个未参与筛选的新种子；5种子仍不是大样本的普遍优越性证明。

容量分支若WIDE/DEEP最坏组改善≥0.2%、至少2/3种子改善、均值恶化≤1%，选最坏组最好的一个，与BASE一起在201/202/203上继续到32768；否则不扩大容量预算。筛选失败是完整的负结果，不隐去。方法晋级使用端点，最终best只用验证最坏组最小且均值相比该阶段起点恶化≤1%，完全相等取较早；也报告端点，避免只给best掩盖退化。

上限约120万次新增更新（实际由晋级数量决定），约8000万级新增采样轨迹，另有同数网络贪心baseline。阶段起点校准、验证、最终测试全部另外计数。训练流为在线新样本，因此不是固定数据集上的epoch实验；长训练只检验更新数与新样本量的联合增加。

## 4. 数据隔离、最终测试与统计

新验证每组2048，共8192；新degree30测试每组8192，共32768。另封存degree20/40各8192个net，作为容量/长训练模型跨degree迁移的次要测试。验证、校准、测试使用独立命名空间，检查跨split精确重复及与上一轮验证/测试重复。训练进程禁止打开任何test开头的NPZ。测试推理必须等待全部筛选、父模型、晋级训练完成和全局模型哈希冻结；先写不可变selection.json再首次读取测试坐标。

输出原始长度mean、逐组mean、worst-group、P95；单次贪心推理，不混入多次搜索。保留逐net拓扑和线长以便独立重算。degree20/40无需重新训练、无需oracle，Actor.degree按测试输入设置，不更改网络权重。

五个预注册统计槽：E50长预算vs12288的mean和worst；验证选出的mean冠军vs同预算E50的mean；worst冠军vsE50的worst；容量冠军vs同预算BASE的worst。空槽保留不补齐。对所有槽统一给99%双侧区间（Bonferroni名义族95%），10000次种子及相同逐组net的双层配对bootstrap。改善=(baseline-candidate)/baseline，正数为好。探索支持门槛：≥0.5%、多数种子改善、CI下界>0，稳健性比较还要求均值恶化≤1%。区间不解决小种子数和验证选择偏差；新测试解决测试复用，不能自动使所有科学结论变成确认性结论。其他超参、batch、跨degree和best检查点比较全标为探索性。

## 5. 运行、恢复、准入和验收

所有新增代码、配置、复制的纯RL父模型、数据、临时目录、GPU缓存、日志和结果都在本目录。上一轮产物只读，父模型复制后校验SHA256。版本协议和源码在预检后冻结。

先通过环境/目标公式测试、连续运行vs恢复精确相等、每种架构与batch的GPU小样本、微型全流程，再启动正式tmux队列。最多8张GPU同时训练、每任务3个CPU线程；只在连续资源采样符合显存与利用率门槛时准入，保留context和余量，不修改或终止其他任务。本目录新增磁盘上限28GiB、全盘余量至少20GiB；本轮是隔离的纯RL扩展，旧主线含参考解缓存的100GiB入场条件不适用。预估本轮约15–25GiB，不清理别人的数据。

每256步保存原子latest完整状态，每1024步验证；仅保存阶段起终点、预注册batch配对端点及best，其他进度保留日志。run锁、GPU锁、PID/start_ticks/boot_id、心跳、退出码、断点Actor/优化器/组权重/优势EMA/RNG都可追溯。磁盘/显存不足时自身任务保存并暂停等待，不改变batch和预算。调度器异常恢复时先核对已有worker，不重复启动。结束自动生成模型表、预算、训练曲线、逐net文件、哈希和统计报告；只有全体预定任务及报告验收通过才标记完成。工程预检通过不等于实验结果已通过。
