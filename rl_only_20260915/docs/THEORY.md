# 纯强化学习内部反馈的 REST / WDRO：可行性、成本、误差与验证方案

日期：2026-09-15。研究目录：`rl_only_20260915/`。

## 0. 用户纠正后的目标与结论

本次要求不仅是不调用 GeoSteiner，还要去掉 MST、HPWL、几何最优性下界 B 等确定性参考算法，训练反馈全部来自当前学习系统自己产生的动作及其结果。因此，之前的 `oracle_free_20260915` 下界/MST 方案不满足这次更严格要求；其权重、训练状态与参考指标都不沿用。

**理论上可行。** REST 只需看到“自己铺设的线有多长”，就能用策略梯度学习缩短线长；Critic 学习当前策略的期望成本，无须最优解或替代最优解标签。WDRO 的内部攻击器也可用同一线长反馈寻找更难的输入。

**必须保留的东西是环境反馈，而非求解器。** 计算已给定动作铺出的线段长度，与在所有可能树中寻找一棵较短树，是不同操作。若连自己动作的长度、合法性和坐标距离也不允许测量，系统就失去了“短线更好”这一任务信号，不能验证是否学会优化本任务。本方案保留这些环境测量，禁止利用它们求出参考解、最优值或近似最优值。

本方案不用 GeoSteiner、MST、HPWL/B、Hungarian 匹配、其他路由器、最优值缓存、旧预训练权重或基于它们训练的教师。最严格的算法路线为 **REST 强化学习策略 + 学习得到的价值基线 + 强化学习对抗坐标策略**。Random、ES 和 Critic 坐标梯度可作为无参考解的诊断对照；其中 ES 是零阶优化，不能因为无需求解器就改称为强化学习。

本文给出理论和已选定的六分支辨别性实验；参数绑定以本目录冻结协议和代码为准，运行状态不由本文宣称。独立审查入口为 [THEORY_REVIEW.md](THEORY_REVIEW.md)。

## 1. 这不是首次发现“没有最优标签也能训练”

本地原始 `/remote-home/Guilin/DRO/DRO/WDRO-REST/train.py` 第 80–92 行已经用 sampled 树长 `lengths` 直接更新 Actor 和 Critic：Actor 的反馈为 `length−prediction`，Critic 做 `MSE(prediction,length)`。第 107–113 行按 greedy 输出长度验证，没有在这些损失中使用最优参考值。

当前 WDRO 扩展后来改成 `L/L★−1`，并让候选评分、Critic 搜索标签、ES 分数和 RL 攻击奖励都依赖 L★。本次工作是让这整条鲁棒训练链重新只依赖自身环境代价，同时明确目标变化、训练误差与可评价边界。它不把原始策略梯度思想当作新理论贡献。

## 2. 决策过程与唯一任务反馈

### 2.1 状态、动作与线长

输入是固定物理窗口内的 n 个 pin 坐标 `X=(X₁,…,Xₙ)`。本轮固定窗口 `[0.1,0.9]²`：对生成器的原始 `[0,1]²` 输出统一做 `0.1+0.8X`，不作逐 net 包围盒归一化，也不计算任何按 net 的几何难度尺度。近重复 pins 拒绝采样；坐标扰动先逐项裁剪到 `±0.08`，再把最终坐标裁剪到窗口。这样避免把 HPWL 或类似量悄悄放回 reward 分母。

REST 的动作先选择一个起点，随后每一步把一个尚未连接的 pin 接到已连接结构，并选择 L 形路径的朝向。动作序列 a 产生 n−1 个 terminal 连接对。环境检查其连接结构合法，并测量得到：

\[
C(X,a)=L_{eval}(X,a),\qquad R(X,a)=-C(X,a).
\]

本次唯一的主优化反馈是这条实际成本 C。Actor 看不到同一 X 的参考最短树、近似算法树或最优线长。

### 2.2 测量函数与历史实现一致

动作对 `(u,v)` 在 `x_u` 上铺竖段，在 `y_v` 上铺横段。对每个 pin，把自己的竖段集合合为 span、横段集合合为 span，然后累加各 span 长度。这是历史 REST `eval.c` 的记账语义，以纯 NumPy 实现，不加载旧混有 GeoSteiner 包装的动态库。

该测量只“数一数已经铺好的线”，没有选择新边或参考树。当不同 pins 共用 x 或 y 时，历史记账可能重复计入重合 spans；物理线段并集可能较短。本轮固定记账语义以保持可复现性，报告中不把它自动称为去重后的物理长度。

合法性检查和线长测量是强化学习环境的一部分，不是树优化算法。最终产物保存坐标、动作 topology 和测量值，独立验收可重算 C，而不重新运行模型。

### 2.3 为什么不把 Critic 的输出直接当 reward

若只最大化一个会随训练改变、且不锚定任何实际线长的神经网络分数，Actor 可以学会利用 Critic 的误差，而不改善路线。学习内部反馈仍必须以实际动作后果为目标。Critic 的作用是预测这个反馈、减少方差或引导提案；最终训练成本和最终候选排序仍以环境实测 C 为准。

## 3. 方案 A：REINFORCE 与学习得到的价值基线

固定输入分布 P，令 `πθ(a|X)` 为 Actor 动作概率：

\[
J(\theta)=\mathbb E_{X\sim P,a\sim\pi_\theta}[C(X,a)].
\]

状态价值 Critic `Vφ(X)` 的目标为：

\[
V^\pi(X)=\mathbb E_{a\sim\pi_\theta}[C(X,a)\mid X].
\]

它预测“**我当前这套策略平均会花多少线长**”，并不预测“所有策略中最少要多少线长”。用本次动作的实测 C 训练：

\[
\mathcal L_V=\mathbb E[(V_\phi(X)-\operatorname{detach}(C(X,a)))^2].
\]

策略梯度为：

\[
\nabla_\theta J=
\mathbb E[(C(X,a)-V_\phi(X))\nabla_\theta\log\pi_\theta(a|X)].
\]

证明只需用 `Vφ(X)` 与当前动作无关：

\[
\mathbb E_{a|X}[V_\phi(X)\nabla_\theta\log\pi_\theta(a|X)]
=V_\phi(X)\nabla_\theta\sum_a\pi_\theta(a|X)=0.
\]

因此 Critic 即使预测不准，也不会因为这个基线误差而改变理想梯度的期望；它主要影响方差。实际 Actor loss：

\[
\mathcal L_\pi=
\operatorname{mean}[\operatorname{detach}(C-V_\phi)\log\pi_\theta(a|X)].
\]

最小化该 loss，会提高低于预测成本的动作概率、降低高成本动作概率。必须 detach advantage，在使用本次动作更新 Critic **之前**取本次基线，并保留 Actor 的实际采样 log probability。该恒等式不要求对离散树结构求导。[Williams 的 REINFORCE 原始论文](https://link.springer.com/article/10.1007/BF00992696)

**推荐作为首轮主线。** 它改动最少，目标清楚，成本便宜，而且可与原始 REST 训练原理直接对照。

## 4. 方案 B：self-critical，连训练 Critic 都可以去掉

令 `a_g(X;θ)` 为当前 Actor 的 greedy 解码，基线取该策略自身的实测成本：

\[
b_\theta(X)=C(X,a_g(X;\theta)),
\]

\[
\mathcal L_{SCST}=\operatorname{mean}
[\operatorname{detach}(C(X,a)-b_\theta(X))\log\pi_\theta(a|X)].
\]

虽然 b 的值随 θ 改变，但在当前更新中它是停止梯度、与 sampled 动作独立的基线，依然保持 REINFORCE 恒等式。不对基线做额外反向传播。

直观上，自己的 sampled 树若比自己的 greedy 树短，就增加该动作的概率；反之降低。没有外部教师，没有近似参考算法。该机制对应 self-critical sequence training 的通用思想，原论文使用模型自身测试时解码结果作为基线。[SCST 原论文，CVPR 2017](https://openaccess.thecvf.com/content_cvpr_2017/papers/Rennie_Self-Critical_Sequence_Training_CVPR_2017_paper.pdf)

代价是每个训练 X 多一次 greedy Actor 前向及一次长度测量。它可能减少基线误差，也可能因 sampled/greedy 成本差太小、贪心早熟或额外时间而不如学习基线。不能预设 SCST 更好。相同更新数下 SCST 比 value-baseline 多计算，必须单独记账。

不能把 SCST 的 greedy 成本当作最优成本；“比自己 greedy 好”不等于“离最优更近了多少”。

## 5. 更深入的纯 RL Critic：部分树状态的 cost-to-go

若以后需要更低方差，可把状态扩展为 `s_t=(X,已连接pins,当前spans,解码历史)`。新增动作后环境测量 span 增量：

\[
\Delta C_t=C(s_{t+1})-C(s_t),\qquad
\sum_t\Delta C_t=C(X,a).
\]

用 `r_t=−ΔC_t`、不折扣的有限时域回报学习价值：

\[
V^\pi_t(s)=\mathbb E_\pi[\sum_{k=t}^{T-1}\Delta C_k\mid s_t=s].
\]

这是纯环境反馈。TD target 可写为 `ΔC_t+stopgrad(Vψ(s_{t+1}))`，终止状态后续价值为零。它可能改善信用分配，但引入函数逼近和 bootstrap 偏差；截断回报/GAE 会额外引入偏差—方差权衡。

理想的最优动作价值可以定义为：

\[
Q_t^\star(s,a)=\Delta C_t(s,a)+\min_{a'}Q_{t+1}^\star(s',a').
\]

这里的最小值是 RL 的理论目标，不是已知标签。学得一个神经网络 Q 并不意味着已获得 Q★：有限覆盖、函数逼近、离策略分布和 bootstrap 都可能产生误差。没有可验证的全状态误差界时，不得把 learned Q 当作可靠 L★。本轮不把这条状态改造与其他方法一起混做，先验证更直接的终局 REINFORCE。

## 6. 无 Hungarian 的运输成本：必须承认问题空间改变

每个候选由原中心的对应 pin 位移产生，使用：

\[
c_{idx}(X,Z)=\frac1n\sum_i\|X_i-Z_i\|_1.
\]

直接按固定对应关系求平均位移即可，时间 `O(n)`，无 Hungarian、无 assignment 求解。它是**有标签/有对应关系 pin 元组空间**上的 L1 距离；不是任意无序 pin 集合最小匹配后的距离。

对同一个排列 σ 同时重排 X 与 Z，有：

\[
c_{idx}(\sigma X,\sigma Z)=c_{idx}(X,Z).
\]

但只对一侧任意重排，距离一般会改变。因此训练时可对中心与其所有候选同步随机排列，缓解模型对输入索引的依赖；这不会使该成本变成无序集合上的最小匹配距离，也不应这样宣称。

如果网络架构不是精确置换等变，随机排列只是一种数据增强，有限样本上不等于数学上的排列不变性。若以后加入该增强，测试应保留固定种子的同步排列，并可额外报告置换一致性。

本轮代码不额外执行同步随机排列步骤；新生成器的 pin 采样与分布构造按索引对称处理，候选直接继承中心对应关系。共同排列下的成本不变性作为环境性质检查，不能由此声称整个训练系统已实现任意排列等价。

本次对抗目标及 ρ 都围绕 c_idx 重新规定，不能照搬旧 Hungarian 空间的 ρ/λ 或旧模型结论。

本轮不运行分位数校准，直接事先固定 `ρ=0.04`，表示平均每个 pin 的 Manhattan 位移预算为 0.04 个窗口坐标单位。它是人为声明的鲁棒问题范围，不是从最优标签或几何下界推导出来的值。

## 7. 新的 WDRO 目标：绝对线长鲁棒性

定义 `\bar Cθ(Z)=E_a[C(Z,a)]`，理想目标为：

\[
\min_\theta\sup_{Q:W_{c_{idx}}(P,Q)\le\rho}
\mathbb E_{Z\sim Q}[\bar C_\theta(Z)].
\]

符合对偶成立条件时可写为：

\[
\min_{\theta,\lambda\ge0}\lambda\rho+
\mathbb E_X\sup_Z[\bar C_\theta(Z)-\lambda c_{idx}(X,Z)].
\]

这是线长目标在新有对应 pin 空间上的 WDRO，不是旧相对 regret-WDRO。相关对偶数学依赖实际状态空间、可测性与增长条件；有限候选实现不能由这个公式自动取得连续最优性保证。[Gao 与 Kleywegt 的 WDRO 研究](https://arxiv.org/abs/1604.02199)

本轮实际内层使用 greedy 实测成本：

\[
F(X,Z)=C(Z,a_g(Z;\theta))-\lambda c_{idx}(X,Z).
\]

有限候选包含 X，选 F 最大者，然后在所选 Z 上用 sampled C 做外层 REINFORCE。λ 更新仍为：

\[
\lambda\leftarrow\max\{0,\lambda+\eta_\lambda(\overline c_{idx}-\rho)\}.
\]

内层 greedy 与外层 sampled 不完全一致；这是工程近似，不是理想双层问题的精确梯度。ρ 约束平均成本，不是所有单个扰动的成本。

本轮冻结 `λ₀=1`、`η_λ=10`、`ρ=0.04`；这些数值对应 raw线长的新尺度。它们不构成训练稳定性或预算严格满足的证明，日志必须保留全部更新成本与 λ 轨迹。

### 7.1 不可避免的目标偏向

没有最优参考归一化后，raw C 会把“输入几何本来需要更长路线”和“Actor 对该输入解得较差”一起当作高成本。攻击可能把 pins 推向窗口边缘、增加展开程度或制造长连线；即使另一个优秀策略也会有更高成本，攻击仍会奖励它。

这不是代码错误，而是绝对成本 WDRO 的定义。固定物理窗口和位移预算限制输入变化范围，但无法消除几何复杂度差异。必须报告实际线长、成本预算、候选位移及 nominal 退化，不能把结果解释成“最大相对最优误差已经降低”。

## 8. 只用学得的参照能否近似 regret

可以提出这样的内部学习目标，但它们都不等价于真实 regret。

### 8.1 旧快照或另一位学习者作参照

让 ψ 是从零训练、冻结一段时间的内部 Actor 副本，定义：

\[
A_{\theta,\psi}(Z)=C_\theta^g(Z)-C_\psi^g(Z).
\]

当 ψ 固定时，对固定 X 的 sampled Actor 更新减去 `Cψ(X)` 只是合法基线，不改变 raw C 的理想梯度；**用于选择对抗 Z 时**，减去状态相关参照却改变了内层目标，寻找的是相对 ψ 更差的输入。

风险是：ψ 本身很差或局部失灵时，该差值掩盖两个模型共同的错误；ψ 很弱时，θ 胜过它也可能离最优很远。若两个 greedy 策略完全相同，差值处处为零，对抗目标失去学习信号。需要快照刷新、交叉对手、对手质量验证和额外前向预算。

### 8.2 用 Critic 的预测作“难度归一化”

可用 `Cθ^g−Vφ` 作为学习差值，但 Vφ 拟合的是 sampled 当前策略成本，这个差值更接近 greedy 与 sampled 行为差异，不是最优误差。`Cθ/Vφ` 还引入分母误差、接近零的数值风险，以及不同输入的未知重加权。不能把一个回归网络命名为“最优值预测器”就得到最优性保证。

### 8.3 学习对手与自博弈的合理用途

更稳妥的纯 RL 用途是**学课程/学难例生成器**：一个策略解题，另一个策略基于真实任务反馈生成有预算的难例。自博弈/非对称自博弈已有这种自动课程思想，但它不自动为本项目提供最优性或收敛保证。[Sukhbaatar 等原论文](https://arxiv.org/abs/1703.05407)

首轮建议用 raw C 固定定义问题，把 learned-gap 作为后续独立消融。否则同时更换反馈、距离、网络初始化和移动对手，无法判断收益来自哪一项。

## 9. 四种无外部参考的候选生成方式

四种方法均只用当前 Actor 的实测 `F=C_g−λc_idx` 复核候选。

1. **Random 对照：** 采样合法坐标位移并选最高 F。它不学习攻击策略，但可测出多候选择优本身的收益。
2. **ES 对照：** 在合法化后的 F 上正反扰动，以分数差形成移动方向。它是零阶优化，不是 RL；无须解参考树，也不能把有限方向估计称为原始离散 F 的精确梯度。
3. **Critic 提案对照：** 用自生成的 greedy C 标签训练独立代理 Sψ，沿 `Sψ−λc_idx` 的坐标梯度提案。训练主 Critic 是 sampled baseline，Sψ 是另一个搜索代理，两者语义不同。候选最终必须用实测 C 重排。
4. **RL 攻击器：** 学习 `pω(u|X,λ)`，令 `Z=T_X(u)`，奖励 `Radv=F(X,Z)`。最大化奖励的 loss 为 `−E[detach(Radv−b)log pω(u|X,λ)]`；log probability 对应实际采样的原始 u，基线不得依赖该次动作。多次独立采样可用 leave-one-out 基线。

本轮轻量实现没有把 λ 作为策略输入，实际为 `pω(u|X)`；λ 只参与奖励，策略适应当前训练价格，不是显式条件于价格。上文 `pω(u|X,λ)` 是更一般的理论形式，增加这个输入不属于已实施改动。

最严格的“两个学习策略相互训练”系统是第 4 项。其他三项是衡量它的必要对照，不将其包装为纯 RL 对手。

## 10. 误差从哪里来，哪些不会造成偏差

| 误差来源 | 对结果的影响 | 本方案的处理与可验证边界 |
|---|---|---|
| 环境长度实现误差 | 所有 reward 都可能偏离任务 | 独立线段区间计算、手算小例、保存 topology 后重算 |
| Monte Carlo 动作采样 | 梯度有随机方差 | 多 seed、足够 batch、相同动作 RNG、报告训练曲线 |
| 状态基线 V 的预测误差 | 动作独立且 detach 时，保持期望梯度；改变方差 | 记录 MSE、advantage 方差；不用它替代真实 reward |
| TD/bootstrapping 误差 | 可引入有偏 advantage 和不稳定传播 | 本轮不用；后续独立评估 |
| 搜索代理 S 的拟合误差 | 提案可能朝错误方向、漏掉高成本候选 | 所有候选实测复核；与同预算 Random 比较 |
| 有限候选内层误差 | 找不到真正最坏的输入 | 标注 K、独立攻击预算；不声称全空间证书 |
| Actor 表示能力/优化误差 | 找不到所能表示的最短解或训练局部停滞 | 从零 seed 重复、初始/最终配对、保留负结果 |
| 学得的参照/对手误差 | 相对它获胜不等于接近最优 | 不用 learned reference 冒充 L★ |
| 测试抽样误差 | 有限测试均值不等于总体均值 | 同 net 配对，seed 与 net 分层 bootstrap，限定分布 |

若记每个样本的 score gradient 为 g、真实成本为 C、基线为 b，则估计量是 `(C−b)g`。在二阶矩存在、独立采样的理想条件下，batch 均值方差按 `1/m` 缩小，但维度、策略尖锐程度、长动作序列和基线误差都会影响常数；不能仅靠这个比例预测需要多少 GPU 小时。

没有最优参照，不是“训练 reward 被近似最优误差污染”：环境 C 仍可准确计算，策略梯度针对 raw C 的含义是清楚的。失去的是精确相对最优误差的评价能力，以及跨实例用最优尺度归一化的能力。

### 10.1 不存在“去掉最优标签必然误差更大”的一般定理

固定 X 时，`C(X,a)` 和 `C(X,a)/L★(X)−1` 对动作的排序完全相同。在理想的充分表达能力、充分探索和成功优化条件下，都可以把策略概率集中到 REST 动作空间中成本最小的动作。该动作空间是否包含真正的全局最短路由是另一个表示能力问题。

有限训练中，两种尺度给不同 X 的权重、梯度方差和对抗选择都不同，所以任一方都可能更好。不能先验承诺纯 RL 一定损失若干百分点，也不能保证损失为零。经验上出现的误差应拆成表示误差、优化/探索误差和测试抽样误差；本次无法直接测得相对全局最优值的那一部分。

### 10.2 为什么内部学习预测不能自行变成最优性证书

在只观察有限动作成本的黑箱 RL 设定中，若仍有可行动作未探索，又不额外使用结构下界或穷尽证明，就可能存在两个与全部已观测反馈一致、但未观测动作成本不同的环境。有限反馈本身不足以证明当前动作全局最优；让多个神经网络拟合这些反馈也没有增加此类证明信息。

这不是说无外部求解器就永远无法找到最优动作：充分随机探索可能找到它，在有限动作空间穷尽全部候选后也可能验证它。也不是说坐标问题本身没有可证明的数学结构。限制在于**本次有限预算、无外部参考/结构界、函数逼近的训练与测试，不能提供那个证明**。学得的低成本解、精确的环境线长测量与可认证的最优性是三个不同层次。

## 11. 计算成本：移除求解器不必然增加总训练时间

记 `A_f` 为 Actor 前向、`A_b` 为反向、`E` 为长度测量、`V` 为小基线网络前反向、`O` 为原最优求解、`H_match` 为原匹配求解成本。

| 环节 | 原最优标签流程的主要成本 | 本次流程的主要成本 |
|---|---|---|
| 一次 value-baseline 训练样本 | `A_f+A_b+E+V+O`（或读取缓存） | `A_f+A_b+E+V` |
| 一次 self-critical 样本 | 取决于旧流程 | `2A_f+A_b+2E`，另有固定管理开销 |
| K 候选实际评分 | `K(A_f+E+O+H_match)` | `K(A_f+E+O(n))` |
| 搜索 Critic 训练 | 最优归一化标签和网络更新 | 自身 greedy C 标签和网络更新 |
| learned-opponent 参照 | 取决于方案 | 每候选额外一次对手前向和长度测量 |

MST/HPWL 和 Hungarian 被移除后也不再有这些 CPU 计算。没有 GeoSteiner 的主要好处是减少每个实际评分的开销、长尾阻塞和标签缓存管理，尤其是在候选很多时。

但为了达到同样的实际线长，纯 RL 可能需要更多样本：奖励尺度更随输入几何变化，探索不足时没有老师指出更好的动作，SCST 还增加前向。反过来，准确的 action-independent baseline 和更便宜的大量实际采样可能足以弥补。**总时间究竟增减是经验问题，不能先验声称一定更快或一定更慢。** 粗略地 `T_new/T_old=(N_new/N_old)×(t_new/t_old)`：移除求解器主要降低单步 t，而达到目标质量所需步数 N 未知；旧标签已缓存时，省下的求解时间也不能再次重复计算。

报告至少分开：固定更新数质量、实际环境测量数、Actor/代理/攻击策略前反向数量、端到端时间、峰值显存和恢复重放开销。正式排期以 GPU pilot 吞吐为依据，而不是沿用旧求解器实验 ETA。

## 12. 推荐的最小辨别性实验

### 12.1 分支

| 分支 | 主策略学习反馈 | 主训练基线 | 对抗输入生成 |
|---|---|---|---|
| `erm_critic` / ERM-value | 自身 sampled C | 学习的 V(X) | 无 |
| `erm_rollout` / ERM-self-critical | 自身 sampled C | 自身 greedy C | 无 |
| `wdro_random` | 自身 sampled C | 学习的 V(X) | Random，实测 F 选优 |
| `wdro_es` | 自身 sampled C | 学习的 V(X) | ES，实测 F 选优 |
| `wdro_critic` | 自身 sampled C | 学习的 V(X) | 自生标签代理，实测 F 选优 |
| `wdro_rl` | 自身 sampled C | 学习的 V(X) | 学习攻击策略，实测 F 选优 |

本轮选择全部六分支。前两分支回答基本可学习性与 baseline 选择；四种 WDRO 分支回答多候选收益与三种提案机制的额外价值。最严格纯 RL 对抗部署路线是 `wdro_rl`；其他提案算法明确作为对照。

所有方法从零重新初始化，同 seed 共享初始 Actor 与中心输入流，训练 batch/更新数/选模规则/独立 test 相同；绝不接着上一版带 B/MST 的模型继续训练。degree30、三个固定 seed 可作为首轮可执行概念验证，而不是全 degree 的普遍结论。

### 12.2 已冻结的具体规模

| 项目 | 本轮配置 |
|---|---|
| degree / seed | 30 / 101、102、103 |
| 模型数量 | 六方法×三seed，共18模型 |
| 外层预算 | 每模型2,048更新，batch64 |
| optimizer学习率 | Actor、value baseline、搜索代理、RL攻击器均1e-4 |
| 内层候选 | 每中心8个实际评分，含原中心 |
| Random扰动 | Gaussian标准差0.04，按统一规则clip |
| ES | 中心+3对正反探测+1次移动，总8评分；移动步长0.04 |
| Critic提案 | 7个起点，每起点4次坐标梯度步，每步0.01；最终加中心评分 |
| validation | 四分布各256，每128更新一次，最差组mean C选模 |
| test | 四分布各1,024，独立于训练/validation |
| 独立攻击 | 四分布各128中心，每中心统一32候选Random攻击 |
| greedy microbatch | 固定64，尾批复制填充、丢弃冗余输出 |
| 保存与统计 | 每32更新checkpoint；2,000次配对分层bootstrap |

正式外层总计36,864更新、2,359,296个sampled Actor训练样本；12个WDRO任务合计12,582,912次训练候选评分；3个SCST任务另增加393,216次自身greedy基线评分。validation、test、独立攻击、padding和重放开销单列。

四个WDRO分支均更新相同小型greedy长度代理以统一这部分开销；只有Critic分支使用它提案。它们的坐标梯度或RL策略梯度开销仍不同，不把相同候选数称为完全相同计算成本。

### 12.3 数据和选模

训练中心为固定窗口中的 uniform，验证/测试包括 uniform 与预先固定的偏移分布；不按每个 net 的跨度归一化。只保存坐标、ID/分布与模型自产动作/成本，不读取最优标签或旧模型生成标签。

validation 使用相同固定 net 的实际 greedy C，选择预先冻结的最差组 mean C 最小 checkpoint，平局保留更早者；可同时设置 nominal 退化门槛，但不得观测 test 后临时改变选模。

固定 greedy microbatch 与尾批填充，防止批形状改变离散输出。test 只报告最终冻结结果，不用来修改训练长度、攻击步数或奖励定义。

### 12.4 评价不再包含任何 B/MST/HPWL 指标

- 实际 C 的 mean、P95、最差分布组。
- 初始→最终的同 net 长度差，判断是否真正学会缩短输出。
- 相同 seed/相同 net 上各方法长度差及 win rate。
- `C_A/C_B−1` 可描述相对另一个学习模型的成本差，但必须明确 B 是模型名，不是最优值或几何下界；主表优先用绝对差避免歧义。
- 固定随机攻击与 learned 攻击的有限预算结果、对应位移成本。
- learned baseline MSE、策略 advantage 方差、代理排序/改进幅度、每步 λ 和运输预算偏差。
- 训练时间、实际调用量、GPU 型号、峰值显存、三 seed 分别结果。

所有区间针对观测分布与训练 seed；不能输出精确 optimality gap、真实 regret 百分比、近似比或 Wasserstein 全局证书。三个 seed 的不确定性很大，多重比较也应明确。

## 13. 可选的内部 self-imitation，不在首轮混入

只保存自己曾经采到的较低成本 `(X,a,C)`，提高其动作概率，可以在完全无外部教师的条件下利用历史经验。SIL 文献提出从自身过去较好经验学习的机制，可作后续设计依据。[Self-Imitation Learning 原论文](https://proceedings.mlr.press/v80/oh18b.html)

但重复训练历史动作属于离策略/辅助目标，不能继续把整个更新称为原 on-policy REINFORCE 的无偏梯度。需要评估缓存偏向、老策略分布、样本权重和额外训练开销。“历史最优自采样动作”只表示已采样集合中最好，不是全局最优。首轮不同时加入，以避免探索收益与 replay 收益混淆。

## 14. 验收结论的四层边界

1. **约束符合性：** 训练、候选选择、选模、测试都未使用禁止的求解器/几何参考/旧教师。
2. **从零可学习性：** 独立测试中，最终 Actor 相对同一初始 Actor 显著缩短自身输出成本。
3. **实测分布鲁棒性：** 在给定偏移分布、成本预算和有限攻击器下，WDRO 优于无对抗训练对照。
4. **内部攻击学习收益：** 相同预算下，learned RL adversary 的训练结果优于随机候选择优。

后一个层次不由前一个自动推出。若最终只有第 1 层通过而质量没有改善，应明确报告“符合纯内部反馈约束，但本预算下未验证有效学习”；若 ERM 有效而 WDRO 无收益，也必须分别陈述。所有已授权实验与负结果应完整保留。
