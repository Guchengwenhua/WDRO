## 3. 样本量、预算和配对单位

共同限制是 degree30、三个已训练 ERM 父 Actor 101/102/103、四个合成分布。固定模型每分布64个 test 中心，几何在三个 seed 间共享；故是256个独立中心、768个模型—中心对，不能称768个独立训练重复。

| 费用项 | 复核值 |
|---|---:|
| 23 配置搜索 validation：128中心×23×64 | 188,416 greedy请求 |
| 3 seed固定模型 test：256中心×11方法×64 | 540,672 greedy请求 |
| D1/D2 三seed共享标注：3×2,560 | 7,680 greedy请求 |
| D7 十二任务：每任务8,192搜索+1,280validation+3,072三阶段test | 150,528 greedy请求 |
| greedy总计 | 887,296，实际请求与提交预算一致 |
| D7 sampled Actor/REST：12×128×16 | 24,576，单独计账 |

代理新增训练的每个变体为1,024标签、6 epochs。区域池只有256个独立中心，不能把其四个相关轨迹点当作1,024个独立几何来源；验证是128中心×4点=512标签。

D7 每个 seed 有2,048个训练中心，四分支共享；validation每分布64，test每分布256。initial/best/latest均评价，不重复当作独立模型。12个任务中2个 validation best 为更新0：`refresh32_raw_s101` 与 `refresh8_ema_s101`；其余 best 更新见 [task_schemas_and_budgets.json](task_schemas_and_budgets.json)。

D3 的 adam16 每中心输入梯度前向/反向各1,008行，baseline各504行。两者真实评分都是64，但 D3 使用两倍梯度行数并有Adam状态开销。现有结果支持所选搜索配置在等真实评分预算下更高惩罚分数，不支持更高计算效率或Adam本身的纯单因素优势。

## 4. λ、数据隔离与选择

## 5. 科学结论是否改变

原表目前只有D3达到“九项Bonferroni区间有利且三个seed同向”的规则；其宏惩罚分数差为 +0.002457433，区间 [0.000694624, 0.004257825]。该值是原始regret尺度的惩罚分数差，不是直接的求解器线长降幅。D1、D2、D4、D5、D6与D7不满足原门槛；不能写成等价或方向无效。

本审查的声明更正**不改变这些数值和条件性判断**。固定模型分析代码在test前已有持久绑定，D3仍可作为本次独立test中的有利信号；不能将全套九项清单都称作所有实验前的严格预注册，也不能将D7探索性区间当作已经覆盖训练随机性的总体保证。

梯度诊断的原解释基本准确：

- 相对no_move，baseline平均轨迹差−0.000397155，正向比例约46.36%；best-of64差+0.000776999的95%区间跨0。不能据此说多数梯度方向有效。
- 相对random_direction，平均轨迹与best-of64的点态区间有利，但这些是未同时校正的机制诊断。随机分支仍执行梯度计算，耗时不能代表真正无梯度算法成本。
- 63轨迹先在中心内聚合再bootstrap，避免把同一net的63轨迹当独立样本；bootstrap不重采样模型seed，区间只条件于已有三模型。

D7执行了完整2×2因子配置，但现有报告统计的是三个分支减baseline，没有单列正式因子主效应与交互对比。可以解释四分支的描述性动态，不能宣称已检验交互作用。D7还没有独立压力测试，因此普通test regret结果不能直接当作新的鲁棒性证书。
