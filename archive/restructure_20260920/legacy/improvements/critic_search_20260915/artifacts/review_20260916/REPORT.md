**D3 计算代价边界：** 两者每中心均为 64 次真实评分，但 Adam16 的梯度前向/反向各 1,008 行，baseline 各 504 行，即两倍梯度行数。因此现有证据支持等真实评分预算下更强的搜索，不能证明等总计算量更高效，也没有隔离出 Adam 相对步数变化的单独贡献。分数提升不是直接的线长降幅。

**梯度机制诊断：** baseline 相对不移动的平均轨迹分数下降 0.000397，正向轨迹约 46.36%；best-of-64 的收益区间跨 0。相对匹配尺度随机方向，平均轨迹和 best-of-64 的点态区间有利。这些未作同时校正的诊断不支持“多数 Critic 梯度方向有效”的说法。随机方向实现仍计算梯度，其耗时不能代表纯无梯度方法。

## 4. 可接受范围与尚未证明的内容

- 七个方向各完成了冻结的最小对照版本，不是 tmp2 所有子建议都已逐一三 seed 验证。D3–D6 所有候选进入 validation，仅各方向获选配置进入三 seed test；具体覆盖见[协议审查表](protocol_review/REPORT.md)。
- 范围为 degree30、三个固定父模型、四个合成分布。固定 test 每分布 64 个共享中心，共 256 个不同中心、768 个模型—中心对；不能当作 768 个独立训练重复。
- Bootstrap 在分布内按配对中心重采样，共 5,000 次，三个模型使用相同抽样索引；区间条件于已有模型，没有覆盖重训随机性。校正后尾部分位数也受有限 bootstrap 次数影响。
- D7 仅 128 更新、batch16、每中心 4 次搜索评分，四分支形成 2×2 配置；本报告未正式检验因子交互，未接入 D3 新搜索、未做独立强攻击压力评测。12 个 best checkpoint 中 2 个为更新 0。
- 这些是有限候选搜索和短继续训练的实证，不是连续 Wasserstein 最坏风险证书；区间跨 0 不证明等价。
