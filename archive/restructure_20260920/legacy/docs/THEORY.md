# 理论与方法：合并阅读版

## 1. 项目对象和评价量

REST 接受无序二维引脚集合，输出离散的 rectilinear Steiner 树结构。研究 degree 为 10、20、30、40、50。输入逐 net 平移、按最长边等比例归一化，保留纵横比和逆变换；比较对象共用相同预处理与 REST 架构。

设主模型为 θ，GeoSteiner 参考最优长度为 L★，greedy 解长度为 Lᵍθ，搜索真实损失为：

```text
ell_g(Z) = L_g(Z) / L_star(Z) - 1
c(X,Z) = min_permutation mean_i || X_i - Z_perm(i) ||_1
f(X,Z; theta,lambda) = ell_g(Z) - lambda * c(X,Z)
```

cost 是 Hungarian 平均 L1；相同 degree 下对引脚排列不变。所有真实分数都需要主 Actor 的实际输出和精确参考值，Critic 预测不能替代它们。

## 2. WDRO 的预算和实际有限搜索

理论动机是以 nominal 分布 P 为中心，在平均运输成本不超过 ρ 的分布中优化最坏期望损失。实际实现使用有限候选近似内层最优；非负价格 λ 根据选中候选的平均成本与 ρ 的偏差更新。

```text
Z_i = argmax_over_scored_candidates f(X_i,Z)
lambda_next = max(0, lambda + eta_lambda * (mean_cost - rho))
```

ρ 是平均预算，单个候选可以超过它。当前主线用 validation 选定 q75，并按 degree 对训练扰动 cost 单独标定；degree30 的 ρ≈0.02747183268。q75 指训练候选成本的分位数标定，不表示覆盖 75% 的未来测试分布。

主线每个中心生成 32 个 Random/Sobol 扰动并保留原 X。低成本预筛后仅“原 X + 三个扰动”作真实评分，因此 K=32 不等于 32 次真实评分。Hard Mining 按 regret 选难例；WDRO 还扣除 λc。

## 3. 两种 Critic 角色与内外层差异

训练主 Critic 是 action-independent baseline：它拟合 sampled 策略的期望 regret，用于降低 REINFORCE 方差。主 Actor 在选中的 Z 上采样连接动作，再用真实 sampled regret 更新。

搜索代理是为当前 Actor 的 greedy regret 单独校准的函数 Cψ。候选生成可沿 Cψ(Z)−λc(X,Z) 的输入梯度前进，最终候选仍按真实 f 复核。这一梯度属于代理，不是原始离散 greedy 构树损失的精确导数。

内层按 greedy loss 找候选，外层按 sampled loss 训练，两者并不完全相同。搜索更强只能先支持“内层找到了更高分数”；主模型泛化改善需要额外的相同起点、训练预算、选模和独立评测证据。

## 4. 三条候选生成路线

| 路线 | 提案机制 | 已完成 v3.1 的范围 |
|---|---|---|
| 校准 Critic | 学习 greedy regret 代理，多起点坐标上升，真实复核 | 4/64 次真实评分；死区修复后仍观察到较弱排序相关 |
| Gaussian-ES | 对合法化后的真实目标作正反扰动，用分数差形成搜索方向 | 64 次真实评分，最终按原始 f 保留最佳候选 |
| 一步 RL | 条件策略一次输出整组 pin 位移，用真实 f 奖励训练 REINFORCE | 冻结策略与最小交替训练；不是每 pin 一个 agent，也没有长 rollout |

ES 的方向对应平滑近似，有限采样和步数没有连续全局最优保证。RL 的单次采样期望训练目标与使用时多个候选择优也有差异。具体协议和实验结果见 [v3.1 汇总](improvements/ADVERSARIAL_V3_1.md)。

## 5. 2026-09-15 七方向研究入口

tmp2 建议围绕代理数据覆盖、拟合目标与选模、更新规则、初始化和多样性、真实评分预算分配、位移限制与合法化、接入训练后的代理刷新与 λ 更新节奏分别开展研究。梯度方向消融用于识别机制。详细数学方案、冻结配置、评分账本与实际实验放在 [本次独立目录](../improvements/critic_search_20260915/)。

需要分别识别代理误差、方向作用、候选数量和真实评分预算的贡献；保持输出 regret 尺度，任何额外标签、验证搜索及真实反馈均计入成本。相邻候选函数差只能作为有限移动监督，不能声称获得非光滑真实函数的精确梯度。

## 6. 可以提出什么结论

主指标是 mean、P95 和最差分布组 regret，另有 nominal 退化门槛。相同预算、相同中心的配对比较有助于排除输入差异，但多个条件格不是多个独立训练重复。有限搜索结果、未校正的多重比较及少量固定 seed 都限定了结论范围。
