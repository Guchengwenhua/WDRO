# Week bank experiment package

Executable controller manifest: jobs.json. No GPU job was launched by its author; do not run a second standalone queue. Root controller handles external scale/geometry dependencies, resources, deadlines and SIGTERM. All new code/metadata are here; artifacts is a symlink to /attached/remote-home1/Guilin/DRO/Codex/week_bank_20260930/artifacts. Existing active experiments are untouched.

run_week.py takes --job-id, --arm geo|k3|lagged3|qualifiedbest3|selected, --degree10|30, --seed101|102|103, --updates2000|10000, optional --import-from parent-run-dir and --selection-file gate JSON. Add --evaluate-only only after training to evaluate full frozen test groups. CUDA_VISIBLE_DEVICES is assigned by controller; runtime uses logicalcuda0 with0.1memory cap andCPU1, all caches/tmp rooted in this directory. Each manifest has argv/cwd/dependencies/absolutecompletion/estimatedseconds/kind and gate_file when needed.

Successful training writes artifacts/<job>/complete.json with complete:true only after the target update and dev result exist. SIGTERM is handled by the copied original trainer, saving the atomic current checkpoint and writing paused.json with complete:false; no complete marker is created. Resume uses unchanged args and latest checkpoint. If already at target but finalization was interrupted, dev/marker completion still runs (fixes the original early-return metadata gap). Test writes evaluation_complete.json separately and resumes at completed groups. Input scientific identity, frozen CLI and source degree/seed/rho/batch/reference arm are checked on import. Model, optimizer, scheduler, RNG, lambda and saved teacher bank remain unchanged during migration. The old terminal-refresh skip causes one documented boundary window; this is exact continuation of saved state, not an uninterrupted-from-scratch10000step claim.

Qualified-best is always measured in its own matched2000stage before gating, rather than globally discarded based on another method. Gates are predeclared in protocol.json and implemented by gate.py using dev.json or original scale validation results only. Each bank branch is judged separately; failed or missing evidence gives allow:false with a reason. For dependency semantics, gate-skipped tasks count as terminal, and missinglong results close the laterbranch. Never use final tests in gates. Gate JSON uses allow:boolean. Matched and long gate jobs use kind:gate; the long gate always_runs after all long branches become terminal, including skips. Always-run report is kind:summarize with always_run:true and dependencies on all other jobs, so controller must run it at finalization even with skips/failures/paused runs.

REPORT.json/REPORT.md inventory partial and complete outcomes, actual costs and turnover, seed effects and500replicate same-instance stratified bootstrap versus matched Geo. Final/latest is primary; identical selectedstep0best does not establish equivalent training. Instance CI does not cover seed uncertainty; actualseed mean/range/std are separate and no equivalence margin is prespecified. Geo elapsed-time accounting starts here; old imported solve counts and teacher accounting are subtracted for newwork summaries. Event accounting respects resume cursor so repeated work appears. Original cached-reference-hit fields on bank methods are not actual scalarcache hits; reference_accounting is authoritative.
