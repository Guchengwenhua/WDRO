# 训练期间几何熵与困难程度诊断

对本次加速协议的 bank 与后续几何训练进行独立 CPU 监测。读取原子保存的 latest.pt，不修改训练、队列、选模或验收门槛。单线程 CPU，每轮扫描后等待 60 秒；实际周期另含评估耗时，可能跳过中间检查点。

固定样本：每个 degree 的四个分布分别从既有 validation 集用固定随机种子抽取 256 个实例，共 1024 个。保存抽样索引和实例 ID；不按标签选择。复用已存在的独立 GeoSteiner 参考长度，以 L/Lref−1 为困难程度。这是模型在该实例上的当前困难程度，不是模型无关的固有难度。

沿当前模型贪心解码轨迹计算现有实现的几何熵 G 和普通归一化熵 Hnorm，逐决策平均。G 的概率是给定第一端点与历史后的条件分布，不是完整联合动作熵。

每个检查点、每个分布分别报告 Spearman、实例配对重采样 500 次的 95% 区间、Pearson，以及最高熵 10% 样本对最高误差 10% 样本的富集倍数。误差阈值并列全部保留，因此同时记录实际困难样本比例。原始六种不确定性分数、长度、参考及实例 ID 保存到 NPZ。

区间条件于该检查点与固定 validation 样本，不代表跨训练随机种子的稳定性；跨时间重复区间未进行多重比较校正。此诊断是探索性的，不提供因果结论，也不替代正式独立测试。CPU FP32、推理 batch 64 与正式 GPU 评估口径分开记录。后续验收应以各方法共有的训练样本预算和检查点比较，不能把多个时间点当成独立重复实验。

运行入口：launch_monitor.sh。产物目录：artifacts/geometry_monitor；REPORT.md 为每个任务最新结果，correlations.csv 为已观测完整时间序列，heartbeat.json 为当前状态，monitor.log 保留运行历史（包括已修复错误）。
