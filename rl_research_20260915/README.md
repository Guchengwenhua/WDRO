# RL 攻击器与 REST 共同训练研究

本研究按2026-09-15请求，提出并实现多种强化学习攻击器，在独立分支比较固定主模型上的搜索能力，以及主模型和攻击器共同学习的效果。当前状态见 [docs/STATUS.md](docs/STATUS.md)。

## 方案

- [详细理论](docs/THEORY_REVIEW.md)：目标、六个改进方向、推导、原始论文、工程选择和结论边界。
- [冻结协议](protocol.json)：degree30，seeds201–203，51项GPU任务。
- [运行与恢复](docs/OPERATIONS.md)：持久会话、进度、检查点和自动验收。
- [最终报告](artifacts/report/REPORT.md)：全部任务完成后产生；文件缺失表示尚未交付科学结论。

| 方向 | 实际实现 | 主要问题 |
|---|---|---|
| PPO | λ条件化高斯提案、固定行为策略、4轮裁剪更新 | 一次昂贵反馈能否更有效地训练提案器 |
| best-of-K PPO | 最大值的替换基线优势 | 训练目标是否匹配最终多候选择优 |
| 序列PPO | 原中心加7步反馈、历史最佳增量奖励 | 同样8次评分能否更有效地搜索 |
| pin-agent MAPPO | 每pin共享策略、中心化上下文/价值、per-pin ratio | 高维联合动作更新与信用分配 |
| MADDPG bandit变体 | 连续pin动作、集中式Q、固定对手回放 | 能否从真实反馈学到有效动作方向 |
| 历史对手共同训练 | 当前REST加最多3个本轮历史REST | 减少只对当前对手适应的风险 |

REINFORCE、Random、ES为攻击对照；共同训练另含同预算ERM。REST自身保留离散策略REINFORCE；没有把它直接改名为连续动作MADDPG。

## 范围与指标

沿用相邻正在运行分支的纯RL约束：训练和评价只使用Actor自身输出动作的线长，不使用精确最优解、MST、几何下界、Hungarian或外部预训练权重。环境窗口固定为`[.1,.9]²`；平均对应pin的L1距离定义运输代价，`rho=.04`，对原中心最大逐坐标位移`.08`。

每seed首先从零训练256步共同ERM起点。六种攻击器各在固定起点上训练256步。十种继续训练分支各训练256步，batch32。独立测试含四分布、每分布1024nets，以及每分布128中心的Random32/ES32攻击。

该指标衡量真实自身线长，不能说明相对最优解的误差。相同评分预算也不等于相同计算：序列方法、PPO更新、padding行数和攻击预训练成本均另记。独立压力测试λ=0；它不是rho约束下的连续最坏风险证书。三seed、短训练、degree30结论只属探索性验证。

## 文件

`env_geometry.py`复制并绑定现有纯RL环境；`policies.py`实现六种攻击器；`runner.py`实现共享起点/固定攻击/共同训练；`scheduler.py`动态调度；`report.py`独立核验哈希、预算、几何与统计；`tests/`含数学和恢复检查。所有新增产物实际位于本目录，未使用目录外存储链接。
