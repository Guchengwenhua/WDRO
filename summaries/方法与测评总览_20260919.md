# DRO/Codex 方法与测评总览

资料快照：2026-09-19。本文按“方法是什么 → 目前用什么数据、测出了什么 → 方法与测试覆盖总表”的顺序整理。

依据项目当前协议、实现、CSV 和最终验收报告撰写。本次是资料汇总，没有重新训练、运行攻击或重做全量科学验收。文中“完成/通过”引用既有交付证据；“支持改善”另按各实验的统计标准判断。

当前有效的参考 regret 主线是 **precision_v2**，三路线改进采用 **v3.1**。旧 v1 的参考精度问题、旧 v3 的 greedy 批形状问题已有纠错版本，旧数值不进入本文比较。近期 RL-only、RL 六方向和论文迁移的状态以各分支最新验收为准，不能只看较早的项目总状态页。

## 1. 目前有哪些方法

### 1.1 先分清求解器、训练规则和攻击器

项目的基本任务是：给定一个二维引脚集合，REST 的 **Actor** 输出构树动作/拓扑，再计算它生成的解的线长。degree 指一个 net 的引脚数。

这些名称分属三个层次：

| 层次 | 解决的问题 | 本项目实例 |
|---|---|---|
| 求解策略 | 给定引脚，怎样生成树 | REST Actor；扩展的 Timing-RST、Hub、Buffer Actor |
| 外层训练规则 | 用哪些输入、怎样给损失加权来训练 Actor | ERM、Mixed ERM、GroupDRO、Hard Mining、WDRO |
| 内层困难样本生成 | 对固定 Actor，怎样移动引脚，使它表现更差 | Random/Sobol、CEM、Gaussian-ES、Critic 梯度、RL 攻击器 |

因此，“ES64”有时表示一个搜索器，有时是“用 ES64 搜索器继续训练出来的 Actor”。**搜索器分数越高越强，训练后 Actor 的线长/regret 越低越好。** 两种结果不能相互代替。

还需区分两种 Critic：训练 Critic 预测 sampled 策略的平均代价，作为 REINFORCE 的方差降低基线；搜索 Critic 拟合当前 Actor 的 greedy 代价，用其输入梯度生成困难坐标。它们的标签、作用和验收指标不同。

### 1.2 五种主线训练方法

以下五种方法共用 REST 架构、同 degree 的 DAC21 预训练起点、三个训练 seed，以及统一评价规则。主线正式规模为每模型 2,000 updates、batch256。

| 方法 | 大致做法 | 与其他方法的主要区别 |
|---|---|---|
| **ERM** | 在 nominal `uniform` 输入上最小化平均损失 | 标准平均风险基准；主线 Actor 仍通过强化学习训练，并不是监督标签分类器 |
| **Mixed ERM** | 每批均衡混合四种分布，等权优化平均损失 | 用显式多分布覆盖增强泛化；应作为独立基线保留 |
| **GroupDRO** | 同样取四组数据，按指数权重提高高损失组的训练权重 | 针对预先定义的组优化，不主动搜索连续坐标 |
| **Hard Mining** | 在候选坐标中选真实 regret 较大的样本，再训练 Actor | 与主 WDRO 使用匹配的候选和真实评分预算，但没有运输惩罚 |
| **WDRO-REST** | 选择 `regret − λ×运输成本` 最大的候选，再训练 Actor；根据平均成本更新非负 λ | 在困难程度与偏移成本间权衡，目标由平均运输预算 ρ 定义 |

主线真实搜索损失和运输成本为：

```text
rθ(Z) = Lθ,greedy(Z) / L*(Z) − 1
c(X,Z) = min_π (1/n) Σ_i ||x_i − z_π(i)||₁
fθ,λ(X,Z) = rθ(Z) − λ c(X,Z)
λ_next = max(0, λ + ηλ × (mean_selected_cost − ρ))
```

`L*` 来自精度修正后的 GeoSteiner；`c` 是无序点集的 Hungarian 平均 L1 距离。ρ 约束的是平均运输成本，不是每个样本的硬半径。

当前主 WDRO 配置为 **Random/Sobol K32 + Hungarian-L1 + learned λ + q75 标定的 ρ**。K32 表示 32 个扰动，连原中心共 33 个几何候选；MST/HPWL 几何预筛后，只对“原中心 + 3 个扰动”进行真实 Actor/reference 评分。因此主线每中心是 **4 次真实搜索评分**，不是 32 次。degree30 的 ρ 约为 `0.02747183268`。

外层 Actor 在选中坐标上重新采样动作，以真实 sampled regret 做 REINFORCE 更新；内层使用 greedy regret，两者存在差别。GroupDRO 在数学上也可使用自身线长作组损失，但项目当前主线 GroupDRO 的训练历史使用参考 regret，不能将其标成已完成的 RL-only GroupDRO。

依据：[主线理论](THEORY.md)、[阶段 0–5](../wdro_precision_v2/docs/stages/STAGES_0_5.md)、[主线与纯 RL 的训练差异](../benchmarks/rl_only_vs_mainline_20260919/docs/TRAINING_DIFFERENCES.md)。

### 1.3 Random、CEM 和高斯平滑 / ES

| 方法 | 机制 | 已有实际版本 |
|---|---|---|
| Random/Sobol / RandomTop4 | 生成随机、低差异或结构扰动；预筛后真实择优 | 主线 32 个扰动、4 次真评；v3.1 的 RandomTop4 对照 |
| Random64 | 直接真实评价一批随机候选，保留最好者 | 每中心 64 次，包括原中心；用于搜索对照和继续训练 |
| CEM64 / CEM256 | 迭代采样，选 elite，再更新提案分布 | 64 档为 4×16；256 档为 16×16；elite=4，中心计入预算 |
| **Gaussian-ES** | 用正反高斯扰动的真实分数差估计搜索方向，再移动搜索中心 | v3.1 ES64；纯 RL 中另有 8 次评分训练搜索和 ES32 压力测试 |

高斯平滑的含义是把合法坐标参数上的真实目标 `F(u)` 换成邻域平均 `Fμ(u)=E[F(u+με)]`，再用正反函数值差估计方向。**项目中已经实验化的“高斯平滑”主要就是 Gaussian-ES**，不是另一套需要重复计数的独立 REST 网络，也不是已验证的 randomized-smoothing 鲁棒证书。

v3.1 ES64 使用 `μ=0.02`、4 对方向、7 轮，含原中心共 64 次真实评分；最终按原始 `regret−λc` 选择所有已评分候选中的最好者。ES 不要求对硬构树和精确参考求解器反向传播，但每次真实探测仍有评价成本。

依据：[v3.1 最终研究报告](../adversarial_v3_1_20260912/docs/研究结论与交付.md)、[主线 validation 消融](../wdro_precision_v2/docs/阶段5_Validation搜索与消融验收报告.md)。

### 1.4 Critic 梯度上升及七个改进方向

基本方法是训练一个代理 `Cψ(Z)` 拟合当前 Actor 的真实 greedy regret，从多个起点沿 `Cψ(Z)−λc(X,Z)` 上升；每步限制位移并合法化，最后用真实评分择优。

v3.1 区分 **raw Critic4**、**calibrated Critic4**、**calibrated Critic64**。校准版修复输入计算图及输出死区，并用 greedy regret 标签训练代理。基础搜索每条轨迹 8 步、步长 0.01、RMS 归一化，随机起点尺度约 0.02，合法化前相对中心逐坐标位移上限 0.08。这里的梯度是代理梯度，不是完整真实 greedy 损失的精确梯度。

后续 `critic_search_20260915` 做了七个方向。为避免把“讨论过”写成“全部测过”，下面同时列出实际候选和确认范围。

| 方向 | 改什么 | 实际变体与测试范围 |
|---|---|---|
| **D1 搜索区域数据** | 让代理见到梯度搜索实际会访问的坐标 | `uniform_mse` 对 `region_mse`；各新增 1,024 标签、6 epochs；一次刷新，非多轮主动学习 |
| **D2 代理拟合目标** | 除绝对数值外，学习局部相对大小与差分 | `region_mse`、`region_huber`、`region_rankdiff`；后者是 MSE+差分+排序复合目标；均完成三 seed test |
| **D3 更新规则** | 改变步长、步数和优化器 | 步长 `{0.0025,0.005,0.01}` × 步数 `{4,8,16}`，另有 `decay16/adaptive16/adam16`；validation 选 **adam16** 后三 seed test |
| **D4 起点与广度/深度** | 比较起点尺度、结构和多短轨迹/少长轨迹 | `mixed_scales`、`structured_starts`、`wide126_short4`、`narrow21_long24`；选 **narrow21_long24** |
| **D5 真实评分分配** | 把评分分给轨迹中间点，而非只看终点 | `trajectory21_8`、`narrow21_long24`、`trajectory_diverse`；也选 **narrow21_long24**，与 D4 是同一结果 |
| **D6 合法化与有效方向** | 减少归一化/裁剪对搜索方向的影响 | `differentiable_normalization`、`remove_rigid`、`adaptive16`；选 **remove_rigid**，去整体平移及近似径向缩放方向 |
| **D7 训练中代理刷新与 λ 节奏** | Actor 变化时刷新代理，用原始成本或 EMA 更新 λ | `refresh32_raw`、`refresh8_raw`、`refresh32_ema`、`refresh8_ema`，EMA β=0.9；四分支均做三 seed 短继续训练 |

另有 **no_move** 与 **random_direction** 机制对照，分别保留随机起点而不移动、用匹配尺度随机方向代替 Critic 方向。D3–D6 所有候选做 validation，但只有每方向获选配置进入三 seed 独立 test；不能把未获选候选也列成完成正式 test。D7 没有接入新 Adam16 或 D1/D2 新代理。

依据：[七方向结果](../critic_search_20260915/docs/RESULTS.md)、[独立验收与声明更正](../critic_search_20260915/artifacts/review_20260916/REPORT.md)、[实际配置代码](../critic_search_20260915/search.py)。

### 1.5 强化学习：已有三个不同实验体系

**第一套：v3.1 的参考 regret RL 攻击器。** 一步条件策略读取原坐标与 λ，一次输出全部 pin 的高斯位移，合法化后得到真实 `regret−λc` 奖励，用 REINFORCE 学习。固定 Actor 下测 **RL4/RL64**；继续训练中测 **RL frozen4** 和 **RL joint4**。joint 每四个外层更新进行一次攻击策略更新。它依赖 GeoSteiner 参考，不能称为无外部参考的纯 RL。

**第二套：RL-only 的六个训练分支。** 从随机初始化出发，训练、选模、候选评分都只使用 Actor 自己生成的动作线长，不使用最优标签、MST、几何界、Hungarian 或外部预训练权重。

| RL-only 分支 | 做法 |
|---|---|
| `erm_critic` | 自身 sampled 线长 + 学习型 value baseline |
| `erm_rollout` / self-critical | 用同一 Actor 的 greedy 解长度作动作无关 baseline；每训练样本多一次 greedy 前向 |
| `wdro_random` | 随机生成困难坐标，按自身 greedy 线长减运输惩罚择优 |
| `wdro_es` | 用自身线长的正反扰动差做 ES 搜索 |
| `wdro_critic` | 拟合自身 greedy 线长的代理，引导坐标梯度搜索 |
| `wdro_rl` | 学习型坐标对手与 REST 共同训练，是该体系的双 RL 路线 |

这里训练目标换成原始自身线长，运输距离也换成**对应 pin 的直接平均 L1**，ρ 固定为 0.04，输入固定于 `[0.1,0.9]²`，不逐 net 做 bbox 缩放。其 WDRO 与原无序集合/Hungarian/regret 主线是不同的具体优化问题。Random、ES、Critic 是无外部参考的提案对照，但提案器本身并非都属于强化学习。

**第三套：RL 攻击器的六种改进。** `rl_research_20260915` 在纯自身线长反馈下，以一步 REINFORCE 为基础，比较以下六个方向。

| 改进 | 实现名 | 大致机制 |
|---|---|---|
| **1. PPO** | `ppo` | 固定行为策略采集反馈，用裁剪概率比进行 4 轮更新，提高同一批反馈利用率 |
| **2. best-of-K PPO** | `bestof_ppo` | 用最大候选收益和替换基线构造优势，使训练目标贴近“多个候选中挑最好” |
| **3. 序列 PPO** | `sequential_ppo` | 原中心 + 7 步反馈；观察当前和历史最佳分数，以最佳值增量作奖励 |
| **4. pin-agent MAPPO** | `mappo` | 每个 pin 用共享策略、集中上下文/价值；7 步轨迹，按 pin 概率比更新 |
| **5. MADDPG bandit 变体** | `maddpg_bandit` | 集中式 Q 学习联合连续位移方向；固定对手可回放，移动对手阶段每次搜索前清空回放 |
| **6. 历史对手共同训练** | `population_ppo` | 当前 REST 加最多 3 个历史快照，抽取一个对手评分，训练实时 REST 与 PPO 对手 |

MAPPO 的 pin agents 协作移动整组坐标，不是每个 pin 各自与 REST 竞争。MADDPG 是共享 actor 的集中确定性梯度简化版、终止 bandit，不是完整原版多步 MADDPG。历史对手分支是课程/共同训练方法，没有单列固定模型攻击器结果，也不是 Nash/PSRO 求解证据。

该研究还有 **Random、ES、REINFORCE** 搜索对照与 **继续训练 ERM** 对照。不要将这套 256 步探索的 `erm`、`es`、`reinforce` 与前述 2,048 步 RL-only 同名方法的数值直接合并。

依据：[RL-only 方案](../rl_only_20260915/README.md)、[RL-only 协议](../rl_only_20260915/protocol.json)、[六方向最终实现说明](../rl_research_20260915/docs/THEORY_REVIEW.md)、[六方向协议](../rl_research_20260915/protocol.json)。

### 1.6 其他已存在的方法、消融和未完成方案

**主线阶段 5 的九个 validation 配置**：`rho_zero`、`rho_q50`、`rho_q75`、`lambda_fixed`、`k1`、`k8`、`chamfer`、`random_64`、`cem_64`。每个配置在 degree30、seed101 训练 2,000 步；只在规范主方法的三个 ρ 配置中选择 q75，其余是消融，不自动成为主线五方法之一。K1 只需 2 次真评，K8/K32 为 4 次，Random64/CEM64 为 64 次。

**三篇论文 × 基础 WDRO** 已完成 24 个正式运行：四个任务家族各做 ERM/WDRO、各三 seed。仍使用原 Random/Sobol 搜索，不叠加 ES/Critic-gradient/RL 攻击器。

| 家族 | 改动与目标 | 完成范围 |
|---|---|---|
| REST 纯线长对照 | 参考 regret，检验新分支内的 ERM/WDRO 配对 | degree10 的新配对实验，不是 precision_v2 复跑 |
| 2023 ICCAD / Timing-RST | 动态图构树，线长与最长源到 sink 路径加权 | 小 degree 组件接入；未实现完整大 net 分解合并 |
| 2025 DAC / Hub | 学习 hub 选择与停止，MSPD 构树，线长/skew 加权 | 冻结关闭额外 hub bonus；不等同论文完整配方 |
| 2025 ICCAD / Buffer | 联合拓扑、16 类谐波相位和缓冲插入，优化 Elmore 延迟/缓冲数 | 固定合成 RC/负载、局部 greedy 插入；非完整最优缓冲 DP |

论文分支的三个新目标不是纯线长 regret，不能跨家族排一个数值总榜。依据：[论文迁移理论](../papers_wdro_20260915/docs/THEORY.md)、[最终验收](../papers_wdro_20260915/artifacts/review_20260919/REPORT.md)。

**未完成科学验证的条目**也需要保留：`oracle_free_20260915` 因包含 MST/几何下界已暂停；纯 RL 更长预训练、RL-only Mixed ERM/GroupDRO 微调、多轨迹 leave-one-out、部分树 cost-to-go、自模仿等仍属方案。直接对完整真实坐标损失求解析梯度也未形成已验收实验。它们不进入已完成方法的性能排名。依据：[暂停状态](../oracle_free_20260915/docs/STATUS.md)、[预训练方案](../rl_only_pretraining_plan_20260919/docs/PLAN.md)、[RL-only 理论中的后续候选](../rl_only_20260915/docs/THEORY.md)。

## 2. 主要测评数据是什么样的

### 2.1 合成数据：四种分布，但各实验不是同一批样本

| 分布 | 几何特征 | 在主线中的角色 |
|---|---|---|
| `uniform` | 矩形区域均匀随机引脚 | nominal |
| `mix_gauss` | 约 80% 引脚来自 6 个高斯簇，σ=0.04，其余均匀 | 聚簇 OOD |
| `edge_bias` | 用幂变换和翻转使坐标靠近边界 | 边界偏置 OOD；不能解释为“四个高斯簇” |
| `grid_cluster` | 约 80% 引脚靠近 8 条水平行，带小纵向噪声 | 行对齐 OOD；不是严格二维方格网 |

主线先逐 net 平移、按最长 bbox 边等比归一化到规定窗口，保留纵横比。纯 RL 使用固定窗口尺度，不逐 net 缩放。即使都写“四分布”，不同 namespace、坐标处理、degree 和样本规模的结果也不能当成同一测试集。

已完成 RL-only 测试的 `mix_gauss` 共享一个生成的簇布局，相关 bootstrap 结论条件于该布局；不能将很多 nets 当作很多独立簇布局。后续“每 net 独立簇布局”的方案尚未形成新的训练结果。

依据：[主线生成器](../wdro_precision_v2/wdro_rest_min/src/datasets.py)、[纯 RL 生成器](../rl_only_20260915/geometry.py)、[RL-only 独立统计](../rl_only_20260915/artifacts/acceptance_20260919/final_statistics/statistics_review.md)。

### 2.4 指标和统计怎样读

| 指标 | 含义 | 方向与边界 |
|---|---|---|
| relative regret | `Lθ/L*−1` | 越低越好；本文百分数表均乘100，0.01就是1% |
| 自身动作线长 | Actor 自己输出拓扑的 REST span 记账长度 | 越低越好；没有最优参考时不能换算为最优误差，且可能双计共线重叠 |
| 固定模型惩罚分数 / gain | `r−λc` 或 `L−λc`；gain减去原中心分数 | 越高表示攻击更强；必须固定 Actor、λ 和反馈单位比较 |
| P95 | 每批误差/线长的95%分位数 | 描述尾部；通常先每seed或degree/seed计算后平均，不是随意混池 |
| OOD worst-group | 三个 OOD 组的最大平均风险 | 主线口径；纯 RL 分支有使用全部四组最大值的口径，应按原表读取 |
| net-weighted / design-macro | 每个 net 等权 / 每个设计等权 | 回答不同问题，不能只报告对某方法有利的一种 |
| 有限支持 LP 风险 | 在指定候选运输边和平均预算下求最坏分配 | 只对这个有限问题精确；不是连续 Wasserstein 最坏风险 |

“均值最低”与“统计支持更好”分开报告。v3.1 的稳定改善要求配对95% CI有利且三个seed同向，未作多重校正；Critic 七方向使用九项 Bonferroni 同时区间，但主要条件于已有模型；RL系列重采样seed和共同中心，仍只有三个seed且未作多重校正。不同实验的 CI 不代表同一种不确定性。

输入采样、参考求解、攻击器训练、梯度前后向、真实候选评分、padding 和 Actor 外层更新是不同费用。**相同真实评分次数不等于相同总计算量**；共享服务器耗时也不能直接给出受控加速比。

| MAPPO | 4.190568 | 5.003438 | 5.049761 |
| MADDPG bandit | 4.193276 | 5.014855 | 5.057116 |
| 历史对手PPO | 4.159564 | 4.934955 | 4.984039 |

序列PPO相对Random的普通均值降低0.060031（约1.47%），95% CI `[−0.103534,−0.027403]`、三seed同向；但两种独立攻击下的区间跨零。best-of-K的攻击均值点估计最低，相对Random/ERM/REINFORCE的有关区间仍跨零。Random相对ERM的两种攻击均值改善得到本轮未校正区间支持，廉价对照仍有竞争力。

27个对抗共同训练任务中，24个全程平均成本超过ρ，10个最后64步仍超过ρ；最大累计超额约7.74%。固定评分预算也没有消除序列方法的padding/同步额外计算。这些结果限于degree30和短程探索，没有建立严格WDRO可行性或收敛保证。来源：[RL六方向独立验收](../rl_research_20260915/artifacts/review_20260919/REPORT.md)。

### 3.9 三篇论文迁移：交付完成，稳定WDRO优势尚未建立

| 家族 | 四分布mean成本的WDRO相对ERM变化范围 | 解释 |
|---|---:|---|
| REST对照 | −6.052% 至 −4.756% | 三个WDRO best都是初始化；表面差异不能归因训练收益 |
| Timing-RST | −2.307% 至 −0.938% | 各分布仅1/3 seed改善，尾部/LP风险不全面改善 |
| Hub | −0.095% 至 +0.045% | 大多数best选择零hub；收益不稳定 |
| Buffer | −0.848% 至 −0.056% | 有局部均值信号，无稳定跨seed优势或谐波模块单独归因 |

16个“家族×分布”mean比较中，net条件CI有9个排除零，训练seed CI为0/16；P95和有限候选LP风险的seed CI也未建立稳定收益。成本目标不同，这里的百分比是**各家族内成本的相对变化**，不是前面regret百分点，也不能用于家族间排名。来源：[论文分支最终验收](../papers_wdro_20260915/artifacts/review_20260919/REPORT.md)。
