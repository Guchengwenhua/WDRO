# 方向 3–6：搜索机制与等真实评分预算验证

## 公共目标与边界

给定已冻结的 Actor θ、合法中心 X 和父 WDRO checkpoint 的非负价格 λ，真实目标为
`Fθ,λ(X,Z) = Lθ(Z)/L*(Z) - 1 - λ c(X,Z)`。
`c` 始终为每 pin 平均 Hungarian-L1，`L*` 使用 precision_v2 精确 GeoSteiner。
代理目标 `Sψ(X,Z)=Cψ(Z)-λc(X,Z)` 仅生成候选，最后按真实 F 选优。
所有比较含原中心，63个额外候选，因此每中心64次真实评分。
原中心保证返回分数不低于原分数；这只是有限集合的下界，不是连续 Wasserstein 最坏风险的证书。
λ 固定，ρ 不参与固定模型的逐样本硬约束。位移0.08是归一化前的坐标限制，绝不冒充运输球半径。

### 先验方向诊断

固定代理、中心、初始高斯扰动和合法化：比较0步、8步独立随机RMS方向、8步代理梯度。
梯度和随机方向每步RMS均为1，步长0.01；随机分支也计算对应梯度仅供方向/合法化诊断，计算量单列。
三者分别按64真实分数选优，另保存全部候选分数，计算逐配对轨迹终点改善率。
同起点比较排除仅靠63次重启造成收益的解释。随机方向可能比代理更好；不预设正结果。

## 方向3：步长、步数与更新

基本更新 `Znext = gX(clip(Z + α g/RMS(g) - X, ±0.08))`，
`g=∇Z Sψ`；Hungarian匹配离开计算图，采用当前匹配分支的L1导数。
在匹配切换、abs零点、BBox极值切换处仅有分支导数，不能声称为真实F的梯度。

预先固定网格 α∈{0.0025,0.005,0.01}、T∈{4,8,16}。
另比较步长从0.01线性降到0.0025的16步、16步自适应缩步、16步Adam方向。
自适应方案每步检查合法化后的代理分数，不改善时保留原点并把本轨迹步长减半（下限0.000625）。
Adam采用β1=.9、β2=.999、bias correction后方向再RMS归一化，幅度仍由α控制。
每方案63起点、63终点评分，网格在seed101独立validation的四分布平均真实F上选优；不拿test调参。
报告每中心前向/反向次数与wall time，T加倍的改善不当作等计算量效率提升。

参考：[Croce & Hein, 2020](https://proceedings.mlr.press/v119/croce20b.html)讨论图像攻击中步长等问题；这里只借用实验动机，不继承其效果。

## 方向4：起点与宽度/深度

对照初始化δ~N(0,.02²)。候选：(a)尺度混合{.005,.02,.05}；
(b)高斯与轴向稀疏扰动混合；(c)126条4步短轨迹中按代理分数与坐标RMS多样性选63个；
(d)21条24步轨迹，每条在8/16/24步各真实评分，合计63。
后两者每中心均504次梯度样本，与63×8对照相同；包含额外代理筛选前向时仍分别计数。
多样性贪心使用canonical pin排序后的坐标RMS，是便宜筛选距离；真实惩罚始终用Hungarian。
初始尺度改变提案分布，归一化前位移上限保持一致。筛选可能丢失真实最优点，必须由真实F评价。

## 方向5：轨迹真实评分分配

对照63×8仅终点评分；候选21×8在2/4/8步各评分、21×24在8/16/24各评分；
以及63×8的全部轨迹点里按代理分数+多样性选63点。
所有真实评分都是1+63=64。轨迹真实历史最佳只在已评分点中定义，不能把代理历史最大当真实最大。
21×8减少梯度成本，21×24保持梯度样本数；并列报告，避免广度/深度/计算混为一谈。

## 方向6：合法化与有效方向

对照先求合法坐标梯度，再移动、位移裁剪、盒裁剪、bbox归一化、最小间距修复。
候选一把盒裁剪+bbox归一化放入autograd：令 Hx(U)=.1+.8*(clip(X+U)-min)/max(span)，
优化 Sψ(X,Hx(U))；真实执行仍走共享合法化和修复。若出现重合/退化不可微处，该图不能代表修复导数。
候选二把方向投影到与整体平移和径向缩放近似正交的子空间，再归一化步长，以减少被归一化消除的运动。
候选三使用方向3的合法化后分数回溯缩步。保持同0.08范围和同λ，不靠扩大搜索范围获得优势。
记录坐标触边比例、修复/回退、候选重复、提案移动与合法化后移动余弦、最终Hungarian成本。
这些诊断揭示计算浪费，不足以证明优化器收敛、代理无偏或更高degree有效。

## 共同验收

独立validation选择配置；随后冻结配置文件和hash，在3个父模型seed、四分布、每格64个新中心上确认。
保存全部已评分支持点、真实regret/cost/score、所选index，逐样本可复算，调用账本对齐。
报告均值、P95、相对基线配对差及95% bootstrap CI；独立seed仅3个，CI仅作为本数据集条件下探索证据。
多个方向的主比较使用同时校正区间；不利seed、方向和分布全部保留。
